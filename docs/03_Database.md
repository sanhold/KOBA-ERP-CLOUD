## 🗄️ Choix des SGBD & Stockage
- **Base Relationnelle** : PostgreSQL
- **ORM / Query Builder** : Prisma ORM
- **Cache / In-Memory Data Store** : Redis
- **Moteur de Recherche Indexé** : OpenSearch
- **Stockage de Fichiers & Documents** : MinIO (S3-compatible)
