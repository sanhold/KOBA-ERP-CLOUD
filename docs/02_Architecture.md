# 02 - Architecture Globale

## 📌 Vue d'Ensemble de l'Architecture
Ce document définit les principes d'architecture logicielle, les couches applicatives et les patrons de conception de **KOBA ERP Cloud**.

---

## 🛠️ Stack Technique Officielle
- **Frontend** : Next.js + React + TypeScript
- **Backend** : NestJS + TypeScript
- **ORM** : Prisma
- **Base de données** : PostgreSQL
- **Cache & Session** : Redis
- **Stockage d'objets** : MinIO (S3 compatible)
- **Temps Réel** : WebSocket (Socket.io / NestJS WebSockets)
- **Moteur de Recherche** : OpenSearch
- **Authentification & Sécurité** : JWT + Refresh Token
- **Architecture** : SaaS Multi-tenant
- **Conteneurisation & Orchestration** : Docker (Dev/Staging) & Kubernetes (à terme)
