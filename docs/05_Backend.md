## 🛠️ Stack Technique Backend
- **Framework Principal** : NestJS (Node.js) + TypeScript
- **ORM** : Prisma ORM
- **Base de Données** : PostgreSQL
- **Cache & Fast Key-Value Store** : Redis
- **Temps Réel & Evénements** : WebSockets (NestJS Gateways / Socket.io)
- **Stockage de Fichiers** : MinIO SDK (S3 compatible)
- **Recherche & Analytics** : OpenSearch Client
- **Sécurité & Auth** : JWT + Refresh Token Module (Passport / JwtModule)
